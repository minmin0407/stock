# 法人籌碼｜投信外資買賣超

**網站：<https://minmin0407.github.io/stock/>**

每個交易日盤後自動更新，顯示**投信**與**外資**買賣超前十大股票，含**連續買賣超天數**。

涵蓋上市（TWSE）與上櫃（TPEX），已排除 ETF 與非普通股。手機、電腦都能開。

---

## 現在的狀態

已經全部設定完成，**你不需要做任何事**：

- GitHub Pages 已啟用，從 `main` 分支的 `/docs` 資料夾發布
- GitHub Actions 已設為可寫入，每週一到五台北時間 **17:20** 和 **19:00** 自動抓資料並更新網站
- 跑兩次是保險：證交所大約 16:00 後才公布，且資料已抓過的話第二次不會重複做事
- 電腦關機也照跑，全部在 GitHub 的伺服器上執行

### 加到手機主畫面

用手機瀏覽器打開網址：

- **iPhone**：Safari 下方「分享」→ 往下找「加入主畫面」
- **Android**：Chrome 右上角「⋮」→「加到主畫面」

之後就像一般 App 一樣點開，沒有網址列。

## 網站怎麼看

**上方日期列**：`‹` `›` 切換交易日，中間下拉可以直接跳到某一天，「最新」回到最新交易日。你上次看的日期會被記住。

**三個分頁**：投信 / 外資 / 對照（四張榜單一次看）

**表格欄位**：

- **買賣超(張)** —— 原始資料是股數，這裡已換算成張。紅色買超、綠色賣超（台股習慣配色）
- **連續** —— `連5買` 代表已連續 5 個交易日買超。**這是最有訊號價值的欄位**：單日進出可能只是調節或作帳，連續買超才是明確的建倉動作
- **近20日** —— 小柱狀圖，看得出買賣的節奏（螢幕較寬時才顯示）

點欄位標題可以切換排序，箭頭表示目前的排序方向。

歷史日期的連續天數只會用「當天以前」的資料計算，所以你回頭看上個月某一天，看到的數字和當時看到的一致，不會偷看未來。

## 手動觸發更新

平常不需要，但如果想立刻抓一次：

1. 到 repository 的 **Actions** 分頁
2. 左側點 **每日更新法人籌碼**
3. 右邊 **Run workflow**，`backfill_days` 留空，按綠色按鈕

想回補更長的歷史（例如一整年），同樣的地方把 `backfill_days` 填 `500`。

## 檔案結構

```
.github/workflows/update.yml   每日自動更新的排程設定
scripts/fetch_flows.py         抓資料、算連續天數、產生看板 JSON
docs/index.html                網站本體（單一檔案，無外部相依）
docs/manifest.json             加到主畫面用的設定
docs/icon.svg                  App 圖示
docs/data/days/*.json          每個交易日的完整資料
docs/data/board/*.json         每日排行榜（網站實際讀取的）
docs/data/index.json           可用日期清單
```

資料量很小，一年約 3 MB。

`docs/data/days/` 裡是完整的歷史資料，之後想做回測或統計分析，原料都在裡面。

## 想在自己電腦上跑

不是必要的，但如果想在本機測試或做分析：

```bash
git clone https://github.com/minmin0407/stock.git
cd stock
python scripts/fetch_flows.py rebuild    # 用現有資料重算看板
cd docs && python -m http.server 8000    # 開本機網站
```

然後瀏覽器打開 <http://localhost:8000>。需要 Python 3，不需要安裝任何套件。

## 疑難排解

**網站沒更新**
到 Actions 分頁看最近一次執行。紅色叉叉代表失敗，點進去看記錄。常見原因是當天還沒收盤或是連假。

**Actions 顯示沒有寫入權限**
Settings → Actions → General → 最下面 **Workflow permissions** 選 **Read and write permissions** → Save。（目前已設定好，除非之後被改動。）

**上櫃股票沒出現**
櫃買中心近年改版數次，API 端點會變動。程式裡放了 4 組候選網址依序嘗試，遇到暫時性錯誤也會自動重試兩次。上市資料完全不受影響。

要查目前可用的端點，在本機執行：

```bash
python scripts/fetch_flows.py discover-tpex
```

把正確的網址填回 `scripts/fetch_flows.py` 開頭的 `TPEX_CANDIDATES` 即可。

**連續天數看起來偏小**
連續天數只能在已有資料的區間內計算。初始回補 130 天約等於 90 個交易日，所以最多算到 90。之後每天會自動累積。

**想改自動更新的時間**
編輯 `.github/workflows/update.yml` 裡的 cron。GitHub 用的是 UTC，台北時間要減 8 小時（`20 9` = 台北 17:20）。
